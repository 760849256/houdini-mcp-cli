# Bridge 首批连接优化验收记录

日期：2026-11-17\
候选版本：0.3.0a1\
状态：首批连接可靠性改造已交付；完整路线图继续分阶段实施。

## 已交付

- 每 Houdini 实例独立注册，校验进程启动身份、服务代次和连接租约。
- MCP 的一次操作固定目标实例；多实例返回候选，并可通过原有 context 入口明确选择。
- 轻量健康查询独立于场景读取，区分在线与主线程忙碌或暂未响应。
- 同一实例重启后按下一次读取恢复连接；写入前要求新鲜上下文，不自动重放写操作。
- 脱敏诊断持久化并轮转；支持操作与请求关联、分段耗时及控制面板一键导出。
- 保留既有六个日常入口、权限开关、旧 CLI 显式连接文件及完整诊断接口。

验收经过实际 stdio → HTTP → Houdini GUI 主线程。两版均验证了隔离场景中的 Python 创建节点及结构回读、同进程服务重启、主线程等待六秒后的恢复，以及第二个真实 Houdini 进程的注册隔离。22 版最终验收还通过 context 工具实际切换了两个隔离实例。

耗时来自小型空场景的上下文读取，排除模型思考和网络模型服务延迟。首读计时从服务重新就绪后开始，不能当作整个故障持续时间。不同轮次受工作站负载影响，不能据此宣称 22 比 21 更快，或宣称生产任务已提速某个百分比。

## 发现与修正

- Windows 并发替换连接文件时出现短暂访问争用：为原子替换增加有限重试。
- 最初 Houdini 22 GUI 验收发生一次存活握手超时：为尚未提交场景命令的预检增加有限重试；后续两轮通过。
- 初次失败报告仍保留在 artifacts/bridge_acceptance/phase_A_22_GUI_20261117.json，未将失败从验收历史中删除。
